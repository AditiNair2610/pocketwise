# Pocketwise — ₹10K / 30 Days

Responsive React + Vite personal finance experience for the Prompt Run challenge. This project is intentionally split into multiple files and reusable components.

## Features
- ₹10,000 starting budget, current balance, daily allowance and month-end forecast
- Add/delete income and expense transactions
- Decision simulator for spending, saving, cutting a subscription and earning extra income
- Savings goals and progress
- Upcoming commitments that can be marked paid/unpaid
- Monthly subscriptions that can be paused/reactivated
- Financial health and financial risk indicators that respond to money decisions
- Spending breakdown, responsive UI, and a modal for new transactions

## Run locally
1. Install Node.js LTS.
2. Extract the ZIP and open a terminal in the project folder.
3. Run `npm install`
4. Run `npm run dev`
5. Open the local URL printed by Vite.
6. Before submitting, run `npm run build` and fix any errors.

Sample/demo data only; no bank accounts are connected. Financial scores are illustrative planning estimates, not financial advice. Confirm all official challenge requirements and submission format before final submission.
